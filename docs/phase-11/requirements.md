Use existing public order_intent/order/submission_attempt/order_event/fill/fee/outbox tables. Add only execution-owned payload/watermark/evidence/adoption tables and restricted role through a new additive migration. Previously published migrations remain immutable. The public order remains the current lifecycle projection; immutable intents retain original economic commands. State is never authoritative only in RAM.

Risk and principal authorization are required injected server ports, with no permissive defaults. A dispatch consumes one persisted attempt and verifies scoped risk decision/reservation, permission epoch and freshness; adapter authorization independently consumes the transport permission once. PAPER and LIVE remain exact storage modes, but this phase has no Paper simulator or LIVE execution. Only explicitly composed TESTNET/DEMO adapter execution is possible after Risk authorization. Initial economic units are BASE Spot/linear perpetual; quote-budget/contracts/inverse capabilities fail closed until their storage/accounting gate.

The Order Engine adopts Portfolio's existing native execution journal/posting; it never produces a second monetary ledger effect. Fill delivery has permanent scoped identity and immutable content. Partial fill quantity is reconciled against native cumulative quantity without adding it twice. UNKNOWN remains blocking until positive scoped exchange evidence; negative lookup does not authorize a second POST.
