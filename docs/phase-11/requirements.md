## Permanent replay hardening

Hardening baseline: clean main `50eff552cccf35901bc78504fbbd25258c9bcb75`. Before current metadata admission, the service must perform an authorized authoritative durable lookup of the PLACE key and canonical binding/request hash. Exact replay returns the original order/intent/client identity and immutable command, including after metadata/rules replacement and restart. Existing key with different semantics rejects with ORDER_IDEMPOTENCY_CONFLICT. A missing key still requires full current registry/rules and SQL metadata admission. Replay must not append intent/order/command/outbox or advance the client counter; it does not authorize submission or weaken stale-rule/Risk/permission checks. Unit and native PostgreSQL tests must prove these properties.

## Formal AMEND transfer to PHASE 12

Repository review found a Core DTO (`locator + replacement NewOrder`) and generic acknowledgment, but no common contract for in-place amendment versus cancel/replace, partial cancel/replace outcomes, target/replacement identity, quantity relative to prior fills or revision-aware recovery. Binance/Bybit/OKX production factories force AMEND_ORDER UNSUPPORTED; HTX's supported-feature allowlist excludes it. Enabling the DTO would invent semantics unsupported by the accepted adapters.

AMEND is therefore explicitly assigned to **PHASE 12**, before that phase's acceptance gate. First define and test the generic amendment contract and native capability mappings; then implement Order Engine AMEND with its own immutable intent/key, exact target scope, current rules, Risk reservation adjustment, durable attempt, one-use permit, UNKNOWN/restart reconciliation and unchanged original PLACE command. Never emulate it with uncoordinated cancel plus create. Profiles lacking verified native support remain UNSUPPORTED. The PHASE 12 gate must include amendment/fill races, partial/ambiguous outcomes and restart tests; LIVE still requires its separate approval. This task makes the roadmap correction only and does not begin PHASE 12 implementation.
