## Scope and invariants

Standalone `@ctp/exchange-okx`, JSON V5, global Spot USDT and linear USDT SWAP. Four immutable LIVE/DEMO profiles; REST openapi.okx.com; Demo header x-simulated-trading=1 on every REST request, separate wspap public/private/business WS, default TLS port 443. No TESTNET, region guessing, alternate host, caller URL, redirects or raw credentials. Account scope: Futures mode acctLv=2, net_mode, regular trading roles, autoLoan=false, native UID matching server binding and no withdrawal permission. Other account/product modes are UNSUPPORTED until separate proof. Spot tdMode=cash; SWAP tdMode server-controlled cross/isolated, never from order payload.

Public REST → versioned instruments/rules → public WS → private auth/config/balances/orders/fills/positions → sandbox mutation protocol. Preserve Exchange Core's 33 operations, DTO/decimal/capability/cursor/authorization boundaries. No application API composition, DB/ledger writer, Risk/Order/Market Data engine or PHASE 8 work.

- Tests first for every discovered defect. Full regression, real loopback HTTP/WS settlement tests and all existing CI jobs before READY FOR PHASE 8.
- Native REST signature: Base64 HMAC SHA256(timestamp ISO UTC + uppercase method + exact path/query + exact JSON body), scoped passphrase header. WS login: epoch seconds + GET + /users/self/verify. Sign after rate admission waits; bounded fresh endpoint clock and credential resolution.
- Bounded IO and server ports; abort/deadline destroy HTTP/WS sockets and actually settle transport so Core slots can be released. No network on import/factory construction; no exposed IO override or signer.
- Durable Core permit, trusted authorization, separate Demo scope grant and complete server order admission are mandatory. No real private exchange calls without account authorization, no LIVE mutations, no mutation retries. Ambiguous transport/50004/duplicate/malformed/per-item ACK → UNKNOWN; reconcile stable client ID with native reads. Empty/not-found lookup is INDETERMINATE.
- Ordinary ordId/clOrdId never becomes algoId/algoClOrdId. Initial scope admits MARKET/LIMIT and linear reduceOnly; trigger/algo/attached TP-SL/OCO/trailing/amend/close/mode switching are explicitly UNSUPPORTED. Existing single-trigger Core semantics remain intact.
- Spot MARKET uses tgtCcy=base_ccy, banAmend=true and explicit USDT quote; QUOTE_BUDGET is UNSUPPORTED until common BASE observation can be proved. Native Spot maxMktSz is USDT, not BASE. Core local quantity cap is conservative; server admission must additionally enforce full native notional/price/slippage/risk limits from fresh evidence. SWAP sizes/rules/orders/fills/positions are CONTRACTS tied to contractSpecVersion; no implicit BASE order conversion. Only ctMult=1, linear ctVal in base asset are admitted.
- Public book levels normalize to BASE using ctVal for SWAP; candles/trades declare or normalize units deliberately. Unknown instrument or constraint fields fail closed for new risk. Upcoming constraint changes bound metadata expiry. Active cursors are never evicted; terminal pages free slots, continuation is single-consumer and query-bound.
- WS subscribe/login ACK before DATA, with bounded pre-ACK buffering; native seqId/prevSeqId continuity, exact duplicate suppression and conflicting/out-of-order events → resync. Deprecated checksum=0 is not integrity evidence. Private source close requires a fresh authenticated subscription; reconnect/backfill orchestration remains PHASE 9. Wallet delta stream is UNSUPPORTED until complete snapshot reconciliation exists.
