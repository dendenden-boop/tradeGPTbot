Only isolated test fixtures open their gate. HALF_OPEN is observable probe state, not order permission. The storage API itself does not certify that probe evidence is trustworthy.

No callback holds a SQL transaction across exchange I/O. Observability reads bound SQL aggregation to 10001 rows and reject beyond 10000 per set; they are not certified admission snapshots. Read failure or uncertain commit never grants permission. Reopen/read or replay the same immutable control event to inspect committed outcomes; do not advance an epoch based on an uncertain response.

Controllers cannot truncate/delete/overwrite history. There is no TTL auto-resume or restart reset. Existing public pause/circuit records remain extra conservative blockers and their writes acquire the same durable gate. Engine final authorization uses shared global/tenant locks before account locks and holds them through one-use consumption/COMMIT; pause takes the corresponding exclusive lock. Readiness cannot be inferred from an earlier observed RUNNING row.

Before acceptance, the durable Risk gateway still needs stable shared budget locks and certified Portfolio/Market Data snapshots to reconstruct restart and UTC loss baselines, preserve permanent reservation ownership and avoid double accounting.
