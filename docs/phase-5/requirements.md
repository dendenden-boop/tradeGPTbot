## Обязательные контракты

| Область              | Scope и инварианты                                                                                                                          | Приёмочные проверки                                                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Endpoint profiles    | Серверная allowlist Spot LIVE/TESTNET/DEMO и USD-M LIVE/TESTNET; нет пользовательских URL/redirects/fallback между средами                  | Профиль/market/account mismatch, URL injection, региональные ограничения, query escaping                                                                            |
| HTTP/WS transport    | Реальный Node HTTP(S)/WS, bounded body/headers/messages/concurrency; deadline и abort уничтожают underlying operation                       | Loopback серверы: hung headers/body/handshake/close, abort до/после dispatch, освобождение socket и core pending slot, late completion, malformed/oversized payload |
| Decimal/IDs          | Decimal strings сохраняют точность, numeric JSON IDs не проходят через binary float                                                         | ID больше Number.MAX_SAFE_INTEGER, trailing-zero exchange fields, exponent/NaN/negative zero, неправильные units                                                    |
| Metadata/public      | ExchangeInfo filters и отдельные Spot/USDT perpetual instruments; REST ticker/book/candles и WS market data                                 | Реальные документированные fixtures, tick/step, MARKET_LOT_SIZE, нет synthetic 30s OHLC, UTC windows, stale/gap/resubscribe                                         |
| Private protocol     | HMAC signing, account/balances/positions, обычные и algo orders, private events, scoped pagination                                          | Канонические bytes signature, clock/recvWindow, permissions, mode/tenant isolation, IDs binding, ACK не fill, non-authoritative not-found                           |
| Единый algo contract | Единственный внешний trigger активирует child MARKET/LIMIT; вложенные STOP_* запрещены общей schema                                         | RED воспроизведение обеих two-trigger форм, отказ до authorizer/transport; valid MARKET/LIMIT остаются совместимы                                                   |
| Authorization        | Credentials и account binding приходят только из доверенных серверных ports; mutations дополнительно требуют явный sandbox acceptance grant | Default deny, cross-account/ref mismatch, expired grant, async abort, отсутствие raw secrets в ошибках и логах                                                      |
| Mutation ambiguity   | Timeout/connection loss/неопределённый ответ после dispatch → UNKNOWN, никаких blind retries                                                | Lost ACK, late fill, query по exchange/client ID, scoped window и unknown после not-found без достаточного evidence                                                 |
| Rate scopes          | Обязательный серверный admission port получает IP/account/endpoint/symbol cost и response headers; retry не скрывается внутри SDK           | Отказ/зависание limiter, 429/418, unknown budget, подписка/keepalive тоже расходуют соответствующий budget                                                          |
| Packaging/regression | Отдельный пакет, tests/fixtures не входят в production exports, API composition не обходит gates                                            | Full regression и CI Windows/Linux + реальные services/Docker; clean production import                                                                              |

Порядок реализации: public REST → instruments → WS market data → private auth/balances/orders/positions → environment contracts. При обнаружении дефекта сначала фиксируются reproduction/contract tests, затем исправление. Семантика межбиржевого algo задаётся до private/algo реализации.

LIVE trading выключен. Никакого отдельного TESTNET/DEMO аккаунта для реальных mutations пользователь не разрешал; такие acceptance вызовы не выполняются. Mutation protocol проверяется fixtures и локальным сервером, с теми же hash/authorization boundaries. Неудачный публичный probe или отсутствие credentials фиксируется как NOT RUN/BLOCKED соответствующего external evidence, не как успешная торговая интеграция.

Итоговые [контракты](contracts.md) и [verification](verification.md) различают реализованный протокол, выполненные локальные/CI проверки, external evidence и ограничения. READY FOR PHASE 6 разрешён только после полного acceptance; до этого PHASE 6 не начинается. Generic algo и quote-budget orders, которым native protocol не позволяет сохранить обязательные Core identities/quantity, явно UNSUPPORTED и не обходят контракт.
