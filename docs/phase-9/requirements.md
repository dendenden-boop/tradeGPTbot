# PHASE 9 — Market Data Engine requirements

Work starts from main `20523a4455d79c9f4ff77b2cccf6d53d1d6b250a`. PHASE 8's final-main CI [37221754608](https://github.com/dendenden-boop/tradeGPTbot/actions/runs/37221754608) passed. The source of scope is PHASE 9 in the original roadmap and [market-data design](../market-data.md): WS pool, subscriptions, reconnect, stale detection, aggregation, genuine 30-second candles and persistence, with a minimum 300-instrument test. PHASE 10 is excluded until acceptance.

Public feeds are shared by exchange/market/environment/region/instrument, never by an untrusted tenant/account/URL. Pools enforce connection/topic/frame/control/queue limits and retain subscription intents across bounded jittered recovery. TCP, ACK and heartbeat alone cannot establish market freshness or candle completeness. Native book ordering remains in the completed exchange adapters; a gap invalidates the book and requires a fresh snapshot, without assuming universal sequence +1.

Seven UTC half-open intervals are 30s/1m/3m/5m/15m/30m/1h. Prices and quantities use exact decimal strings. Deduplication includes public feed identity and native trade identity. Event time and deterministic identity ties determine open/close. Late corrections create a new revision; missing history remains GAP/UNVERIFIABLE. Empty verified intervals have no OHLC. A minute candle is never split into 30-second bars.

Runtime registry, durable store, connection/control limiter and recovery evidence are mandatory injected server dependencies. State, checkpoint, candle revisions and publication events commit atomically with owner fencing. Restart restores deduplication and quality, but requires fresh source synchronization. Queue overflow, stale metadata, storage failure and unprovable history fail closed for downstream consumers. Existing order/risk/auth/LIVE and anti-reuse invariants are preserved. Published migrations are immutable; any required persistence schema is additive.

Acceptance requires tests for all seven timeframes, decimals, boundaries, ties, duplicates, out-of-order/late input, empty versus outage, stale/reconnect, queues, restart/fencing and 300 unique instrument keys. Report measured fixture limits honestly; a deterministic/loopback benchmark is not a 24-hour production soak. Full existing regression and all CI jobs must pass before READY FOR PHASE 10.
